# Ethics Policy

**Last updated:** February 22, 2026

## Our Mission

BugTraceAI is built for **defensive security**. Our mission is to help security professionals identify and fix vulnerabilities before malicious actors can exploit them. We exist to make software safer.

## Core Principles

### 1. Authorization First

BugTraceAI must **only be used on targets you are authorized to test**. This is non-negotiable. Before running any scan, you must have:

- Written permission from the system owner, **or**
- Explicit inclusion in a bug bounty program scope, **or**
- A signed penetration testing contract.

### 2. Defensive Purpose

BugTraceAI is a **defensive security tool**, not a hacking tool. It is designed to:

- Help bug bounty hunters find and report vulnerabilities through legitimate programs.
- Assist contracted pentesters in performing thorough security assessments.
- Enable developers and security teams to test their own applications.

It is **not** designed or intended for unauthorized access, data theft, disruption of services, or any other malicious activity.

### 3. Responsible Disclosure

When you find vulnerabilities using BugTraceAI, you should:

- Report them through the appropriate channels (bug bounty platforms, direct contact with the organization).
- Allow reasonable time for the vulnerability to be fixed before any public disclosure.
- Follow the disclosure guidelines of the relevant bug bounty program or organization.

### 4. Community Responsibility

As a member of the BugTraceAI community, you share responsibility for how this tool is perceived and used:

- Lead by example in ethical security practices.
- Encourage responsible use among peers.
- Help educate newcomers about proper authorization and legal boundaries.
- Do not share techniques or configurations intended for unauthorized use.

### 5. Legal Compliance

Users must comply with all applicable laws and regulations in their jurisdiction. Unauthorized computer access is a criminal offense in most countries. Ignorance of the law is not a defense.

## Reporting Misuse

If you become aware of BugTraceAI being used in ways that violate this ethics policy, please report it to the team:

## Commitment

The BugTraceAI team is committed to building tools that strengthen security for everyone. We will continue to develop features and safeguards that promote ethical use, and we stand firmly against any misuse of our software.
